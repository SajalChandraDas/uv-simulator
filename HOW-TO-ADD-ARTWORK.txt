How to add or remove artwork
============================

The simulator reads its artwork library from this website folder on GitHub
(github.com/sajalchandradas/uv-simulator). Changes appear on all simulators
1-2 minutes after you commit.

ADD A DESIGN
1. Open the repository on GitHub, open the "art" folder, click
   "Add file" > "Upload files" and drop in the image.
   - JPG, about 1800-2500 px wide. Use a simple file name without spaces,
     for example beach-sunset-waves.jpg
2. (Optional) Upload a small copy, about 320 px wide, with the same file name
   into the "thumbs" folder. This only makes the thumbnails load faster.
3. Open artwork.json, click the pencil icon and add one line, for example:
     {"title": "Sunset Waves", "cat": "Beach", "file": "beach-sunset-waves.jpg"},
   "title" is the name customers see, "cat" is the category tab.
   A new category name automatically creates a new tab.
4. Click "Commit changes".

REMOVE A DESIGN
Delete its line from artwork.json and commit. (The image file can stay.)

CATEGORIES
Abstract, Beach, City, Country and Color are set up now. Small texture
images in the Color category (under 1000 px) repeat across the surface
like a real finish instead of being stretched.

Customers' own uploads are never stored. They stay in the visitor's browser.
