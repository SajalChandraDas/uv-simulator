How to add or remove artwork
============================

1. Put the image (JPG, about 1500-2500 px wide) in the "art" folder.
2. Put a small copy (about 320 px) with the same file name in the "thumbs" folder.
3. Open artwork.json and add one line for it, for example:
     {"title": "Sunset Waves", "cat": "Beach", "file": "beach-sunset-waves.jpg"},
   "cat" is the category tab it appears under. A new category name creates a new tab.
4. To remove artwork, delete its line from artwork.json.
5. Drag the whole folder onto your Netlify site's Deploys page to update.
